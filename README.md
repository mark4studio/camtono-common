# camtono-common

Helper utilities for extending [Camtono Customizer](https://getcamtono.com/customizer) — a powerful customizer framework for the **Camtono WordPress theme**.

`camtono-common` provides a set of tools and functions to help developers seamlessly integrate custom controls, register icon packs, and extend the customizer’s capabilities with minimal code.

---

## ✨ Features

- ✅ Register new **icon packs** for use inside Camtono
- ✅ Add **custom controls** to the customizer UI
- ✅ Utility functions to enhance modular extensibility
- ✅ Built with developer experience in mind

---

## 📦 Installation

```bash
npm install camtono-common
